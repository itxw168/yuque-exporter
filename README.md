# 语雀知识库导出工具

## 项目简介

这是一个用于导出语雀公开知识库的工具，支持将语雀知识库中的文档导出为Markdown格式，并保持原始图片链接，可直接导入飞书知识库。

**开发者**: xiaowei  
**GitHub**: https://github.com/itxw168

## 功能特点

- ✅ 支持导出语雀公开知识库的所有文档
- ✅ 导出格式符合飞书知识库导入要求
- ✅ 保持原始图片URL，无需下载图片
- ✅ 自动获取Windows下载目录作为默认输出位置
- ✅ 支持自定义导出位置
- ✅ 可视化界面，操作简单
- ✅ 实时显示导出进度和日志
- ✅ 支持中途停止导出

## 如何使用

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行程序

双击运行 `启动程序.bat` 或在命令行中执行：

```bash
python gui_app.py
```

### 3. 导出知识库

1. 在"知识库URL"输入框中输入语雀公开知识库的URL
2. 默认输出目录为Windows下载目录，也可以点击"浏览"按钮自定义输出位置
3. 点击"开始导出"按钮
4. 等待导出完成，查看导出日志

### 4. 导入飞书

导出完成后，将生成的 `.md` 文件导入飞书知识库即可，图片会自动显示。

1. 仅支持导出公开的知识库，私有知识库需要登录认证

3. 图片保持原始URL，无需下载，导入飞书后会自动显示
4. 建议使用Python 3.8或更高版本
